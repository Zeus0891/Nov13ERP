# ERP Platform Copilot Context

## Project Overview
This is an enterprise-grade ERP platform built with TypeScript, Node.js, Prisma, and PostgreSQL. The platform serves construction, field service, and project-based businesses with comprehensive AI-first capabilities.

## Architecture Patterns
- **Multi-tenant architecture** with row-level security (RLS)
- **Domain-driven design (DDD)** with bounded contexts
- **Microservices-ready** modular structure
- **Audit-first** design with complete actor attribution
- **AI-first** integration across all business processes

## Database Architecture

### Multi-Tenant Isolation
- Row-level security (RLS) implementation
- Composite foreign keys using `[tenantId, id]` pattern
- 85% tenant-scoped tables (~310 tables)
- 10% global tables (~35 tables)
- 5% hybrid tables (~18 tables)

### Audit Trails
- Universal `Actor` pattern for attribution
- Microsecond-precision timestamps
- Immutable audit events
- Complete data lineage tracking

### Data Classification
- Built-in compliance frameworks
- Automated retention policies
- GDPR/CCPA support
- Data classification tags
